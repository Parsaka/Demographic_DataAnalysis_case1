# Global Demographic Data Analysis (2002–2022)

Descriptive analysis of life expectancy at birth and under-5 mortality across 227 countries, 5 regions and 21 subregions, and how both changed between 2002 and 2022.
Project I of the *Introductory Case Studies* course, TU Dortmund.

**Project page:** https://parsa-kamali.de/projects/demographic-data-analysis.php

## What the analysis does
- Distributions of life expectancy and under-5 mortality by sex.
- Regional and subregional comparisons (2022).
- Correlation between life expectancy and under-5 mortality.
- Change analysis 2002 vs 2022.

## Repository contents
| File | Description |
|---|---|
| `Pythoncode.py` | All analysis and plotting code |

## Tech stack
Python, pandas, matplotlib, seaborn

## How to run
```bash
pip install pandas matplotlib seaborn
python Pythoncode.py   # expects census2002_2022.csv in the same folder
```
